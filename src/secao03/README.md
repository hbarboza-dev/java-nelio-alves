# Seção 03 - Estruturas repetitivas 
## O que aprendi
- Como utilizar o DEBUG
- Estrutura repetitiva enquanto (while)
- Estrutura repetitiva para (for)
- Estrutura repetitiva faça-enquanto (do-while)
## Conceitos-chave
Explicações curtas com trechos de código:
```java
while (condição) {
    comando1
    comando2
}
///Usado quando não se sabe previamente a quantidade de repetições que será realizada.

for (inicio; condição; incremento;) {
    comando1
    comando2
}
///Usado quando se sabe previamente a quantidade de repetições, ou o intervalo de valores.

do {
    comando1
    comando2
   } while (condição);
   ///O bloco de comandos executa pelo menos uma vez, pois a condição é verificada no final.

```
