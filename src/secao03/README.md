# Seção 03 - Estruturas repetitivas 
## O que aprendi
- Como utilizar o DEBUG
- Estrutura repetitiva enqaunto (while)
- Estrutura repetitiva para (for)
- Estrutura repetitiva faça-enquanto (do-while)
## Conceitos-chave
Explicações curtas com trechos de código:
```java
int x = 10;
System.out.println(x);
```
