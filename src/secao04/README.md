# Seção 04 - Outros tópicos básicos sobre Java
## O que aprendi
- Restrições e convenções para nomes
- Operadores bitwise
- Funções interessantes para String
- Comentários em Java (básico)
- Funções (sintaxe)

## Conceitos-chave
```java
modificadorDeAcesso tipoDeRetorno nomeDoMetodo(tipo parametro1, tipo parametro2) {
    // corpo do método
    return valor; // omitido se o tipo de retorno for void
}
```
