## Exercícios
- [Exercicio01.java](Exercicio01.java): Faz um programa para ler dois valores inteiros e depois mostrar na tela a soma desses números.
- [Exercicio02.java](Exercicio02.java): Ler o valor do raio de um círculo, e depois mostrar o valor da área deste círculo com quatro casas decimais.
- [Exercicio03.java](Exercicio03.java): Fazer um programa para ler quatro valores inteiros A, B, C e D. Calcule e mostre a diferença do produto
  de A e B pelo produto de C e D segundo a fórmula: DIFERENCA = (A * B - C * D).
- [Exercicio04.java](Exercicio04.java): Fazer um programa que leia o número de um funcionário, seu número de horas trabalhadas, o valor que recebe por
  hora e calcula o salário desse funcionário.
- [Exercicio05.java](Exercicio05.java): Fazer um programa para ler o código de uma peça 1, o número de peças 1, o valor unitário de cada peça 1, o
  código de uma peça 2, o número de peças 2 e o valor unitário de cada peça 2. Calcule e mostre o valor a ser pago.
