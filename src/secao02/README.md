# Seção 02 - Estrutura condicional
## O que aprendi
- Expressões comparativas
- Expressões lógicas
- Estrutura condicional (if-else)
- Operadores de atribuição cumulativa 
- Switch-case
- Expressão condicional ternária
- Escopo e inicialização
## Conceitos-chave
Explicações curtas com trechos de código:
```java
int x = 10;
if ( x >= 10){
        System.out.println(x);
    }
/// Verificação se X é maior ou igual a 10

```
